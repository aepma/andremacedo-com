117 · Jewel Beetle

The scarab Chrysina has no green pigment. Its shell is chitin stacked in a slow helicoid — a molecular staircase — and a spiral only returns light that twists the same way it does. So the beetle reflects almost only left-circularly-polarized light.

Drag to change your viewing angle — the hue slides green→gold as the layer spacing foreshortens. Click to cycle the polarizer: none → left filter (color survives) → right filter (color dies to mud). That collapse is the proof there was no pigment — only structure.

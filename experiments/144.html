144 · Tie a Number

A khipu string holds a number in knots. Near the top, one knot per hundred. Lower, one per ten. At the bottom, a long knot: its turns are the ones. A row with nothing tied is zero.

The red string on top always holds the total. It ties itself.

Tap a row on any string to tie one more there. Nine wraps back to zero. Keys 1 to 5 pick a string, then type a number.

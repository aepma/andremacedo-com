## What it does well

- It opens by posing as a dull default slide, then edits itself into the real
  thing. The surprise is earned because the start looks ordinary.
- One self-contained page. Every visual is drawn in code; there are no image
  files.
- Thirteen directed scenes, each with one clear idea.
- Ten named transitions between scenes (fade, portal, fold, wash, flaps, slam,
  daybreak, line, tear). Each cut carries something from one scene into the
  next instead of hiding the seam.
- Pacing feels directed: it plays itself, and the keyboard steps through it.
- A generated sound score that supports the scenes.

## What to take for andremacedo.com

Andre liked this form, and the home page now takes it (SOUL.md, The form,
2026-11-27): one full-screen directed piece, a short run of scenes, one idea
per scene, very few words, designed transitions, playing itself, stepped by
scroll, keys or tap.

- Start plain, then transform. The plain start must already say who Andre is
  and how to reach him.
- One idea per screen, carried by the visual, with very few words.
- Transitions with intent, named and designed, not default fades.
- Code-drawn visuals that stay light enough for the 4-second first paint.
